✦ EDITOR DO CATÁLOGO

Seu catálogo, do seu jeito.

Gerencie produtos, fotos, preços, categorias e a identidade da Bartos sem abrir o código. É gratuito e as alterações são publicadas direto no seu GitHub.

Primeiro acesso — como criar sua chave de acesso:
  1. Abra Criar token no GitHub ↗.
  2. Escolha Fine-grained token, um nome como Editor Bartos e a validade desejada (ex.: 30 dias).
  3. Em Repository access, escolha Only select repositories e selecione Bartos.github.io.
  4. Em Repository permissions → Contents, marque Read and write.
  5. Gere e copie o token. Cole-o abaixo. Ele não é salvo no site.
Privacidade: o endereço do painel é público, mas só é possível salvar mudanças com uma chave autorizada. Nunca envie o token para clientes, nem coloque-o no código ou em imagens. Use somente em dispositivo confiável.

Como funciona

Produtos: selecione um item, edite e pressione Salvar no site no topo. O botão Nova foto envia imagens direto para a pasta imagens/ do GitHub.

Publicação: o salvamento cria um commit em catalogo.json. O GitHub Pages costuma levar alguns instantes até mostrar a atualização.

Login: o token é usado somente enquanto o painel está aberto. Fechar ou atualizar a página exige colá-lo novamente.

Arquivos: as imagens já enviadas não são apagadas automaticamente do repositório quando você as remove de um produto.

Segurança: só você deve ter acesso ao token. Restrinja-o a um único repositório e à permissão Contents (Read and write).

Se precisar, consulte a documentação oficial do GitHub.
